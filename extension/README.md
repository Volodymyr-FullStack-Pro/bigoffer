# BigOffer browser button

Saves the job page you are on to the BigOffer board: one click opens the board with that link, the board reads the
page (DOU, Djinni and robota.ua fully; any other site by its title and description) and you confirm the card.

Install (Chrome, Edge, Brave, Arc): open `chrome://extensions`, turn on Developer mode, choose "Load unpacked" and pick
this folder — or unzip `apps/web/public/bigoffer-extension.zip` and load that.

No permissions beyond the active tab; no logins or tokens — the board uses your BigOffer session in the browser.
