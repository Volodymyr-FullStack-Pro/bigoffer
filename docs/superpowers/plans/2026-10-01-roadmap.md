# Подпроект 1 — дорожная карта планов

**Спека:** `docs/superpowers/specs/2026-10-01-job-platform-mvp-design.md`

Спека подпроекта 1 слишком велика для одного плана. Она разбита на последовательные планы; каждый даёт рабочее, проверяемое ПО. Детальный план N+1 пишется после завершения плана N — по реальному коду, а не по догадкам.
